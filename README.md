# Projeto lista de tarefas

Este projeto tem como utilizar uma aplicação de lista de tarefas, onde é possível adicionar tarefas, deletar tarefas, marcar as que forem concluídas e filtrar por ordem alfabética.

##
### Tecnologias utilizadas
- React
- Javascrit
- Bootstrap

## 
### Como utilizar a aplicação
- Faça o deploy do projeto
- Instale as dependências (npm install)
- Execute o projeto (npm run dev)
